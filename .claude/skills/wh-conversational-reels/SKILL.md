# W Heritage conversational reels

Read `.agents/product-marketing.md` §3 and §5 first.

| Part | Rule |
|---|---|
| Hook | Fixed, exact wording. A readable claim or a specific number. Never a polite question. Reuse the hook bank word for word; a new hook is labelled "NEW, for Walid's approval". |
| Body | 3 talking-point ideas, loose enough to say in his own words, like a chat with someone he has known for years. No memorised script. |
| CTA | Fixed: `Écris <KEYWORD>` (EN: `Comment <KEYWORD>`), keyword from the DM list for that pillar. |
| Length | 30–40 s cut from ~60 s; 2–3 takes, keep the most natural; jump cuts between ideas; captions on screen. |
| Retention | Visual change every 2–3 s (visual, sound or movement — one of each per video). Frame 1 shows the claim with the number visible. Hold the answer as an open loop until the end. |
| Language | One video = one language. FR (Quebec, tutoiement) and EN (Ontario) are two native recordings. |

Output template:

```
Reel: <title> · Pillar <n> · Keyword <KEYWORD> · <FR|EN>
Hook (bank #n | NEW): «…»
Frame 1: …
1. …
2. …
3. … (open loop)
CTA: Écris <KEYWORD>
Compliance flags: … (from wh-compliance-gate) or "None found"
```
